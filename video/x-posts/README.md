# X posts

Square (1080x1080, 30 fps) videos for X, in the website's Dark look, drawn with
the same sources as `video/instagram-reel` (`spec/brand/colour-palette.md`,
`docs/design-system.md`). Illustrations in the app's design, not screen
recordings. No sound.

| Composition | Length | Shows |
| --- | --- | --- |
| `GtaIdleGpu` | 20 s | GTA VI is console-only, so the gaming PC sits idle; Nekko Agent loads Qwen3 8B on it and works through a task while you play, then you approve from your phone. No Rockstar artwork, logo, type or colours: the game is named in text only |

    npm install
    npm run render

`out/` is not committed. Fonts in `public/fonts` are copies of
`apps/website/fonts` (OFL-1.1). Preview with `npx remotion studio src/index.tsx`.

# X posts

Square (1080x1080, 30 fps) videos for X, in the brand dark palette (`spec/brand/colour-palette.md`: page `#0B0C14` with `#854F6C` glows, panels `#14151F`, lines `#252735`, main buttons `#190019`), drawn with
the same sources as `video/instagram-reel` (`spec/brand/colour-palette.md`,
`docs/design-system.md`). Illustrations in the app's design, not screen
recordings. No sound.

| Composition | Length | Shows |
| --- | --- | --- |
| `GtaIdleGpu` | 18 s | Three slow beats: "Playing GTA VI?"; "Put your PC to work." with the PC finishing three tasks on Qwen3 8B, then "So you can focus on the mission."; Nekko holding a generic pixel controller (grips in his paws) with "3 tasks done", the Nekko Agent wordmark and nekkoagent.com. No Rockstar artwork, logo, type or colours: the game is named in text only |

    npm install
    npm run render

`out/` is not committed. Fonts in `public/fonts` are copies of
`apps/website/fonts` (OFL-1.1). Preview with `npx remotion studio src/index.tsx`.

Physical OS delivery and visual acceptance remain unverified: Ctrl/Cmd+T creates a new agent and Ctrl/Cmd+Shift+T creates a new terminal through existing wall creation actions. Unknown local models use the explicitly selected fallback only; comparison groups include Fable/Astra, Opus/Sol, Sonnet, Haiku/Luna and open models. These are user-selectable comparison groupings, not verified capability rankings or automatic guesses from model size. Users can disable the fallback. Exact source ids and legacy family estimates are distinguished. Standard text-token estimates exclude per-request long-context premiums, tools, batch discounts, hardware and electricity, and are not invoices. Ollama cloud pricing is linked as an alternative source, not silently substituted for OpenRouter rates. Unpublished sizes, fine-tunes and provider aliases without an unambiguous match remain unpriced or fall back for local usage only.

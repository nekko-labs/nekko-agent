# Model picker, tool categories, Artifacts tab and wall polish (2026-10-15)

User intent (Philip): local models in the picker should read as a name with the file path beneath; provider headings should stand out; the internet switch should turn off internet tools but not local ones, with tools grouped by category; "Focus" should read "Focused"; the wall's three add icons should be in the accent; the agent panel's group **+** must work; and a left-rail **Artifacts** tab should collect what agents produce, grouped by kind, opening the source chat in Focused view.

- **Local model names** `[implemented; TS and Rust golden tests, renderer unit tests]`. The engine daemon's model list (Rust) now carries the engine's friendly `name`, file `path`, folder `location` and load `state` exactly as the TS provider does; before, it dropped them, so under the daemon every engine row showed its full path-like id (`lmstudio/lmstudio-community/...`). The picker shows the short name, the file path as the sub-line, and groups by folder as before. If a local server sends no friendly name and its id is a path, the last segment is the name and the rest becomes the sub-line; cloud ids with a slash (`meta/llama`) are untouched. Filtering also matches the file path.
- **Provider headings** `[implemented]`: in the ink colour at 12px semibold rather than faint 10px capitals; Recent/Starred section labels keep the small faint style so the providers are what you scan for.
- **Tool categories and the internet switch** `[implemented; TS/Rust parity goldens, host routing tests]`. Every tool has a category: **File system**, **Shell & processes**, **Desktop**, **Online** (`fetch_url`, `browser`), **Agent** (plans, questions, sub-agents, watches) and **MCP servers**. Blocking the internet now keeps every local tool and removes Online, MCP and the agent tools that can route to a cloud provider (`spawn_agent`, `delegation_targets`, `agent_watch`, `decide`); before, it removed every tool. The model is only ever offered the remaining tools, and a call to anything else is refused (unchanged gate). The Tools menu is grouped by category with an All on/off per group and stays usable while offline, showing the Online group as off with a note that shell commands are not network-sandboxed. **Boundary:** this is a tool-offer policy plus the existing loopback-only provider check, not an OS network sandbox; a shell command can still reach the network.
- **Focused** `[implemented]`: the wall layout formerly labelled "Focus" reads **Focused** (Ctrl/Cmd+Shift+1 unchanged; the saved mode id stays `focus`).
- **Wall add icons** `[implemented]`: New agent, New image session and New terminal in the toolbar are drawn in the accent colour, with an accent-soft hover.
- **Agent panel group +** `[fixed; isolated renderer reproduction]`. Each project row in the agent panel is a drag source for reordering projects. A press on its **+** (or terminal) button that drifted a few pixels started a project drag, and the click never fired, so the button seemed dead. Pressing either button no longer starts a drag. The existing repository-actions fixture now also sends a real held press that drifts 6px (renderer input events, no OS input): before the fix, 0 creations; after, 1.
- **Artifacts tab** `[implemented; unit-tested; renderer-verified in an isolated fixture]`. A new left-rail destination lists what agents produced across chats: documents a reply linked to (the same links that become artifact cards) and output files the agent wrote with `write_file`, grouped as Documents, Web pages, Designs (pages or images under a design/mockup/prototype folder such as `nekko-designs/`), Diagrams, Data, Office files and Images. Source code and project files (anything under `src/`, `packages/`, `node_modules/` and similar, package manifests, README/SPEC/TASKS/AGENTS) are not listed. Each item names its chat and date; picking one previews it in place with the existing file viewer (HTML stays in its isolated, network-blocked preview), **Open file** hands it to the system, and **Open chat** goes to the Agents wall with that chat as the Focused window (a completed chat opens read-only, as from the agent panel). A filter matches title, filename, chat or path, and completed chats can be included or left out. The index is computed from transcripts in the renderer: no new storage, host calls or permissions; the 60 most recent top-level chats are read, cached transcripts first. A path deleted since is still listed and fails to open. Incognito, image and sub-agent chats are not scanned.

Not verified: packaged desktop app and native OS chrome; the phone apps (no Artifacts tab there); the drifting-press cause was reproduced with renderer input events, not a physical mouse in Philip's running app.

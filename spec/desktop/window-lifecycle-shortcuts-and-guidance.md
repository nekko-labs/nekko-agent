# Window lifecycle shortcuts and guidance (2026-10-12)

Implemented, verification in progress: the focused agent window supports Ctrl/Cmd+Shift+E to Complete, Ctrl/Cmd+Shift+M to Minimize, and Ctrl/Cmd+Shift+Delete to Delete. Hover titles and context menus name the action and its hotkey. Minimize removes the board window only, preserving the item in the Agent panel and any running terminal process. Complete saves a chat into its existing left-panel **Show completed** list. Terminals have Minimize and confirmed Close with the delete chord; terminal completion/history is unsupported because no terminal archive exists. Shortcuts ignore repeated/composing keys, hidden panes and open modal dialogs, and never operate on every window.

**Show tips** defaults on in Settings. The first successfully saved chat completion highlights its existing Show completed control in the left panel with a dismissible explanation. On narrow screens, it automatically reveals the existing vertical agent list drawer and scrolls the highlighted Show completed destination into view without taking focus or expanding completed chats. Closing the drawer keeps the tip pending and highlights the existing Open agent list (Agents) button; reopening restores the destination highlight. Dismiss or opening Show completed clears the current tip. Horizontal lists already expose the destination and do not need drawer guidance. The seen state persists locally and is not consumed by a failed completion save. The highlight is static and adds no animation. Permanent chat deletion and terminal Close use an in-app confirmation with Cancel focused first and an explicit **Skip future deletion confirmations** choice. That persisted choice is independent of Show tips and can be reset using **Confirm deletions** in Settings. No new network calls, permissions, terminal archives or external side effects are introduced by guidance. General cards omit the redundant No project attached text and its empty separator.

Harness security boundary: dynamic renderer arguments are JSON literals with HTML delimiters and Unicode line separators escaped before source construction. Labels are compared as data, never interpolated into selector syntax. Hostile labels, keys and nested reset data must round-trip without executing injected code. This applies to the disposable evidence harness, not a new product permission or execution capability; hidden non-focusable windows, isolated profiles and denied external network/permissions remain required.

Acceptance: verify focused-window routing with multiple chats, terminal minimize without process shutdown, cancel/confirm/skip/reset deletion, one-time completion tips after successful saving only, and matched isolated light/dark wide/narrow evidence. Native macOS/Linux keyboard behavior and Rust daemon terminal processes remain unverified locally.

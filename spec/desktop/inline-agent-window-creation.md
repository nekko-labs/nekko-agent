Video persists wire type `video` and uses the normal selected model and approved tools for scripting, storyboards and available file editing. It is **not a direct video-generation backend**. The detailed media picker also has these two choices. The existing media keyboard shortcut continues to open Photo; Video does not claim an unimplemented shortcut.

## Consolidated creation menus and shortcut hints

Implemented: the Agent Board header replaces its three creation icons with one plus button. Hover or click opens an anchored, viewport-bounded dropdown with exactly Agent, Create or Edit Photos and Videos, and Terminal. Both header and Agents panel menus share the same rows and shortcut labels. Menus use the standard neutral white/light or charcoal/dark surface even on tinted presets. Only the hovered or keyboard-focused row receives the primary accent fill and contrasting text; Agent is no longer permanently highlighted and Terminal no longer has a green active row. A short leave grace period lets the pointer cross into the popup. Outside presses and Escape dismiss the header popup; keyboard opening focuses its first choice and Escape restores the opener.

Shortcuts: Cmd/Ctrl+T creates an agent (Cmd/Ctrl+N remains an alias), Cmd/Ctrl+Shift+I creates an image session without selecting an invented model, and Cmd/Ctrl+Shift+T creates a terminal (existing terminal aliases remain). Cmd/Ctrl+Shift+F opens or closes chat search, navigating to the Agent Board and revealing the Agents panel if needed. Opening search reveals the mobile overlay only below 768 CSS pixels; desktop search must not leave that overlay latched open after a resize. Search exposes this chord in its hover/focus tooltip and in the open popup; Cmd/Ctrl+F remains search within the focused chat. Opening menus or search never starts inference or a shell, changes provider defaults, or adds permissions. Creation requires deliberate row activation or its creation shortcut. Video support remains planned and unavailable.

Acceptance and verification: desktop typechecking and focused shortcut/store/header tests pass. A hidden, non-focusable Electron fixture with an isolated profile and denied network/permissions checks hover opening, viewport bounds at 1200/400 CSS pixels, three shortcut hints, search click/chord toggling, and header keyboard focus/Escape restoration. Matching default-theme before/after captures cover the changed sidebar menu, header, and search surfaces; finite entrance animations are settled explicitly for still captures because hidden Electron pauses them. Real provider inference, host shells, native OS shortcut delivery and native mobile apps are not verified by this synthetic fixture.

# Inline agent-window creation

The 2026-10-06 inline Add-tile and 2026-10-13 toolbar dropdown placements are superseded by the consolidated plus menus below; its earlier verification applies only to that prior design. Implemented, unit and fixture interaction tested: the detailed window picker (still available from the empty wall) opens a viewport-bounded dropdown anchored to its button and portalled outside wall clipping. Chat, Media and Terminal categories remain horizontal (scrollable at narrow widths). Opening it does not move or resize wall tiles, alter the saved split tree, or switch Focus to Grid. Outside pointer and Escape dismiss it. Keyboard opening focuses a choice; Escape/Close dismisses and restores the opener. Pending creation rejects double activation and disables picker dismissal; failures stay visible for retry. Chat selection uses the shared Auto model sentinel, never a literal model named `auto`. Failed chat configuration attempts to delete the newly created record before retry. If cleanup also fails, the mounted wall retains that unconfigured record and reuses it on retry rather than creating a duplicate; the error explicitly reports cleanup failure. This retry reference is local to the mounted view, not durable across navigation/restart. Wall entries and session lists deduplicate by id.

Chat offers an inline model catalog and existing non-archived chats; Media creates a dedicated image session; Terminal creates or opens a shell. The workspace plus menu offers exactly Agent, Create or Edit Photos and Videos (a dedicated image session), and Terminal, with the same Nekko, photo and terminal glyphs as the wall's add buttons. Shell types are chosen under Settings > Terminal > Default shell, with Auto-detect as the default. Opening the menu does not launch a shell or change settings. The composer no longer switches an existing conversation between image and chat types; image parameters remain available within image sessions. No model inference, download or shell starts merely by opening the picker, and selection does not edit provider defaults or favorites.

Mounted synthetic Electron verification now covers actual CommandCenterView creation/options failure and retry, cleanup-failure duplicate prevention, toolbar/Escape dismissal and focus restoration, selected-model chat, image and terminal creation, existing-chat deduplication, Grid/Focus transitions, and workspace image entry through the real store. The fixture denies external requests and uses a fresh isolated profile; no real shell/provider calls occur. For the prior inline design, matched current-main/after full-view light/dark wide/narrow captures and sampled motion frames were directly inspected for clipping, contrast, placement and transitions. For the 2026-10-13 dropdown batch, 48 hidden isolated fixture interactions pass at 1200 and 400 CSS pixels in light/dark, covering bounds, unchanged wall geometry, dismissal/focus return, Budget ranges and Notifications settings. Matching before/after captures and a recording exist, but image and motion inspection remain pending; this batch is not visually accepted or landed. Reduced-motion suppression and narrow reachability pass mounted checks. Verification uses a non-activating off-screen Windows Electron window; native mobile UI is unchanged. Synthetic host behavior is not proof of real provider/shell integration. Video is **planned, unavailable and disabled**; no video generation or shipped status is claimed.


## Consolidated creation menus and shortcut hints

Implemented: the Agent Board header replaces its three creation icons with one plus button. Hover or click opens an anchored, viewport-bounded dropdown with exactly Agent, Create or Edit Photos and Videos, and Terminal. Both header and Agents panel menus share the same rows and shortcut labels. Menus use the standard neutral white/light or charcoal/dark surface even on tinted presets. Only the hovered or keyboard-focused row receives the primary accent fill and contrasting text; Agent is no longer permanently highlighted and Terminal no longer has a green active row. A short leave grace period lets the pointer cross into the popup. Outside presses and Escape dismiss the header popup; keyboard opening focuses its first choice and Escape restores the opener.

Shortcuts: Cmd/Ctrl+T creates an agent (Cmd/Ctrl+N remains an alias), Cmd/Ctrl+Shift+I creates an image session without selecting an invented model, and Cmd/Ctrl+Shift+T creates a terminal (existing terminal aliases remain). Cmd/Ctrl+Shift+F opens or closes chat search, navigating to the Agent Board and revealing the Agents panel if needed. Opening search reveals the mobile overlay only below 768 CSS pixels; desktop search must not leave that overlay latched open after a resize. Search exposes this chord in its hover/focus tooltip and in the open popup; Cmd/Ctrl+F remains search within the focused chat. Opening menus or search never starts inference or a shell, changes provider defaults, or adds permissions. Creation requires deliberate row activation or its creation shortcut. Video support remains planned and unavailable.

Acceptance and verification: desktop typechecking and focused shortcut/store/header tests pass. A hidden, non-focusable Electron fixture with an isolated profile and denied network/permissions checks hover opening, viewport bounds at 1200/400 CSS pixels, three shortcut hints, search click/chord toggling, and header keyboard focus/Escape restoration. Matching default-theme before/after captures cover the changed sidebar menu, header, and search surfaces; finite entrance animations are settled explicitly for still captures because hidden Electron pauses them. Real provider inference, host shells, native OS shortcut delivery and native mobile apps are not verified by this synthetic fixture.

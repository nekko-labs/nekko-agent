# Mascot, polish & onboarding

- **Aphelion mascot** `[shipped]`, a 2D hand-drawn **outline astronaut cat**: every pose is a single ink stroke (`var(--ink)`) on the theme's paper (`var(--paper)`), no color fills except the ginger tail and inner ears, so she rides the theme tokens and works on light and dark chrome without per-theme tuning. A turbulence **line boil** re-seeds a few times a second so the strokes wobble like frame-by-frame ink even when the pose is still; it switches off under reduced motion and while the document is hidden. The body and helmet carry a paper fill purely for occlusion (nearer shapes hide the lines behind them, the inked-animation trick). The activity poses are unchanged: lying (with tucked front-paw rolls peeking under the chest), waking stand, stretching, bug watch, sleeping. `AphelionAvatar` (the Agent tab, the send control, login heroes) and `MiniAphelion` (inline spinner, heavier stroke for 18px legibility) share the outline dome; the boil stays exclusive to the rail mascot so the composer stays calm. (The filled astronaut illustration this replaced is described in TASKS T114/T124.)
- **Onboarding wizard** `[planned]`, the first-run setup described under "First-run setup": a full-screen, every-step-skippable wizard covering theme, providers, and integrations, replayable from Settings, identical on every edition because it shares the renderer.
- **Theme presets** `[planned]`, System / Light / Dark plus a set of elegant tech palettes (e.g. Nebula, Terminal, Nord, Solar, Ember), each rendered as a gradient swatch circle of its colors and previewed live on click. Presets extend the existing token theming (mode + accent + a second accent, plus deeper surface overrides where a palette needs them) and appear in Settings → Appearance too.
- **Polish** `[shipped]`, welcome/empty states, command palette (Ctrl+K), keyboard shortcuts, toasts, onboarding banner, persistent Context Inspector prefs, app icon, boot smoke test. Shortcuts are **discoverable, not folklore**: new agent (Ctrl/⌘+N) and new terminal (Ctrl/⌘+`) show their key hint next to the matching item in the workspaces **+** menu, on the empty-state buttons, and in the command palette. Every chord and its printed label come from one definition, so they can't drift apart, and the labels render as ⌘ on macOS.
- **Refined design system** `[shipped]`, a Warp/Linear-grade visual pass: cleaner cooler neutrals with more breathing room, soft elevation shadows on cards, a **secondary color** (`--accent-2`) paired with the accent into a **brand gradient** (the Agent board wordmark, primary buttons, the rail logo, and the active-nav indicator), focus rings, and tighter heading tracking. All theme tokens (incl. `--accent-soft`) track the user's chosen accent. `[updated 2026-10-01]` Native select popups follow the theme too: every dropdown's option list paints in the surface/ink tokens rather than white-on-white, which the rule previously missed on any select not wearing the `input` class. Approachable for non-technical users while keeping the Aphelion mascot.
- **Border beam** `[shipped]`, the border-beam motion pattern in brand colors: while the agent is working, a violet→cyan beam laps the chat composer's **border only** (the earlier interior color wash was removed, so the surface stays still as you type); the marketing site's hero window mock and download button carry the same beam (the button's speeds up on hover). Static ring without `@property` support; still under reduced motion.
- **App icon: the cat mark** `[shipped]` `[redrawn 2026-10-04]`, an **outline cat head** (two ears, a soft curve of forehead between them, a round jaw, and nothing inside the face) drawn in one **thin stroke with sharp corners** (miter joins, flat caps) on a deep squircle tile with a hairline rim light: simple enough to survive 16 pixels, and the same mark the rail carries beside the wordmark and the desktop title bar carries on its own. Philip chose it from a proof sheet of jaw depths, ear shapes, line weights and corner styles ("D7, thin, sharp"); the first cut of the day had eyes and a smile and round joins, which read soft. One vector source (`apps/desktop/scripts/icon-art.cjs`, mirrored in `renderer/components/BrandMark.tsx` for the in-app mark) is rasterized by Electron itself (`npx electron apps/desktop/scripts/make-icons.cjs`), which writes `build/icon.svg`, `icon.png` (512), a true multi-size `icon.ico` (16/24/32/48/64/128/256), the web/PWA `icon-512.png` + `icon.svg`, the two NSIS installer bitmaps; `node scripts/make-site-icon.cjs` writes the marketing site's `favicon.svg`, which the site also uses as its nav and footer brand mark. Small sizes are drawn with a heavier stroke instead of being downscaled from the large one. The mascot (the full-body agent cat) is unchanged and still fronts the site's hero and social image. This retires the 2026-09 orbit mark (a comet on a tilted ring) and, before it, the pre-rebrand orange pixel cat.
- **Fresh color palette** `[shipped]`, the default accent is a modern **indigo-violet** (`#6d5efc`) paired with a **cyan** secondary into a violet→cyan brand gradient, the current developer-tool look (Linear/Vercel-era), replacing the original salmon/orange. Neutrals were cooled to match. Existing installs are **migrated** off the old default automatically (users who picked their own accent keep it); the accent is still fully recolorable in Settings. Applied across the app, the marketing website, and the branded installer art. The Aphelion mascot stays a ginger cat, and lives in the UI rather than in the app icon (see the orbit mark).
- **One title bar, no menu bar** `[shipped]`, the desktop window used to stack three strips above the app: an OS title bar, a File/Edit/View/Window menu, and then the UI. The menu is gone (it only duplicated shortcuts the app already owns, and macOS keeps its own, which lives in the system bar rather than the window), and the title bar is now the app's: a 38px strip in `--paper` carrying the Nekko Agent wordmark, with the **native window buttons drawn into it** — Window Controls Overlay on Windows and Linux, painted in the app's own background and repainted whenever the theme changes, and macOS traffic lights inset onto the same line. The strip is the drag region, so dragging it moves the window and double-clicking maximises. The wordmark moved out of the rail, which only ever showed it on hover, so the rail starts on its first destination and the app is a row shorter overall. Reload (Ctrl/⌘+R) and devtools (F12) were the only menu items worth keeping and are bound directly. Nothing renders in the web or phone builds, which have chrome of their own. `[updated 2026-10-11]` The strip drops the "Nekko Agent" wordmark: it leads with the cat mark alone at 22px (was 16px beside the wordmark; still named "Nekko Agent" for screen readers), followed by the current view's heading at 17px (was 14px, so it now clearly outranks the 11.5px version pill) and a slimmer version pill (20px tall, was 24px). Verified in renderer captures emulating the desktop chrome (Windows light/dark, macOS traffic-light inset); the packaged app's native caption buttons were not captured. Same day, second pass: the heading is 24px, and every view's page title (Settings, Skills, Workflows, Memory, Design, Connectors, Model Providers, Model Server, Training) shares that size through one `view-title` style so switching tabs never jumps; the version pill drops to 10.5px text and 18px tall; and the cat mark sits 4px below centre so it lines up with the heading's letters rather than its line box. Third pass: the mark is 28px (25% larger) and, off macOS, centred straight above the rail's first icon. Fourth pass: the title bar names every view, not just Agents (the rail labels, so it follows the app language), and in the desktop shell each view drops its own page title so the name appears once; sub-page headings such as Marketplace and New training run stay. The web and phone builds keep their page titles. `[updated 2026-10-12]` The strip is 58px tall (was 38px), giving the cat mark and heading 10px more space above them. The native caption buttons (Window Controls Overlay, `TITLEBAR_HEIGHT`) keep their original 38px size, and on Windows/Linux the trailing title-bar controls (Agents toolbar, developer server controls) sit in that 38px band, with every toolbar label (Focus, Dynamic, Grid, All, Agents, Terminals, Panels) and icon centred on one line with the minimise glyph, measured on the letters' cap-height midline: 21.5px from the top (19px, the overlay's centre, plus 2.5px requested after checking against the real caption buttons). Verified by hidden renderer measurement of the real toolbar; the match with the native glyph was judged by the user in the running app, not captured; native caption buttons and macOS were not captured. `[updated 2026-10-16]` The strip is 46px (was 58px) with 12px top padding off macOS (4px bottom padding on macOS), so the mark, heading and toolbar keep exactly the positions they had (measured identical in a hidden renderer fixture) while the empty band between the toolbar and the top of the Agents board shrinks by 12px; the board gets that height back.

- **Data & privacy controls** `[shipped]`, delete chats by window, Reset configs, Delete everything; settings export/import. `[updated 2026-10-16]` Delete everything (chats with their command logs, memory notes, usage and reply logs, limit snapshots, settings back to defaults; sign-ins, tasks and phone pairing stay) runs in the engine daemon, which first stops any running reply, compaction, image generation and the agent's background processes so nothing writes back what was deleted.

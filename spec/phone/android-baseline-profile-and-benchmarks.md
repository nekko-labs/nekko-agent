# Android: Baseline Profile and Macrobenchmarks

## Intent

Cold start and the first scroll of a long chat should not run through the interpreter. The release app ships a Baseline Profile, and the repo can measure cold start and a 300-message chat on a device. From the 2026-11-26 phone performance audit; tracked in [#3416](https://github.com/nekko-labs/nekko-agent/issues/3416).

## Behaviour

- The release build carries `baseline-prof.txt` and `startup-prof.txt` (generated by `:app:generateBaselineProfile`, committed), installed by `androidx.profileinstaller`, which the app already ships. No new runtime dependency.
- `:baselineprofile` holds the generator and the Macrobenchmarks: cold start, scrolling a 300-message chat, and streaming into it, each with and without the profile where that applies. They run on a device or emulator on request, not in CI.
- The long-chat screen they drive exists only in the `benchmarkRelease` and `nonMinifiedRelease` variants.

## Licences

`androidx.benchmark` (macro-junit4, baselineprofile plugin), `androidx.test.uiautomator` and `androidx.test.ext:junit`: Apache 2.0, test and build time only, not in the APK. `androidx.profileinstaller`: Apache 2.0, already shipped (listed under AndroidX in Open-source licenses).

## Status

Implemented 2026-11-26. Numbers are from an emulator and are in [perf history](../../docs/perf-history.md); no physical-phone run.

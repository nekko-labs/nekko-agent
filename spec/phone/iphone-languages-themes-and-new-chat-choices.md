# iPhone: the desktop's languages and themes, and New chat's effort and computer (2026-10-23)

**User intent:** Philip asked (2026-10-23) for the phone app to support the desktop's languages, to offer the desktop's themes, with a special limited fall app icon for the Spooky theme, and for a new prompt to choose its model and effort, and the computer it runs on when the model is local.

**Status `[implemented 2026-10-23 on the native iPhone app; unit tests, Linux-safe Swift package tests and two new simulator UI tests (theme picker in English, the app in Japanese) pass on macOS; the New chat effort and Run on rows were built and type-checked but not driven in a UI test (they need a paired computer with a local provider); Android: New chat's effort and Run on implemented 2026-10-27 (T201a), languages and presets not started]`**

- **Languages.** The iPhone app ships the desktop's languages (`LANGUAGES` in `apps/desktop/src/renderer/i18n.ts`): English, Español, Français, Deutsch, Português, 日本語 and 中文 (Simplified). Strings live in an Xcode String Catalog (`apps/ios/App/Localizable.xcstrings`, about 500 strings, plus `InfoPlist.xcstrings` for the permission prompts and the New chat quick action). The app follows the iPhone's language; **Settings → Appearance → Language** shows the current one and opens iOS Settings, where iOS's per-app language picker chooses one for Nekko Agent alone. There is no in-app language list: iOS owns that choice. Not translated yet: the widgets, the Share extension, the Watch app, strings built in NekkoKit (mostly computer and relay error messages) and the chat content itself. Translations were machine-drafted and checked for matching placeholders; a native-speaker review is still owed.
- **Themes.** **Settings → Appearance → Theme** lists *Match my computer* (the default: the computer's preset, light/dark mode and accent, as before, now with the preset's surfaces too), *Match this iPhone*, *Light*, *Dark*, the desktop presets and the experimental families. The catalog is `apps/ios/App/Platform/ThemePresets.swift`, written from `THEME_PRESETS` by `packages/shared/src/themes.ios.golden.test.ts` (CI fails when it is stale; `UPDATE_GOLDEN=1` rewrites it). A preset brings its accent and, in the mode it was drawn for, its paper, surfaces, ink and line colours; System, Light and Dark keep the phone's contrast-tuned palette. An id the phone does not know reads as Match my computer.
- **Spooky's limited icon.** While the theme in use is Spooky (chosen, or matched from the computer), the app switches to the alternate icon `AppIcon-Spooky` (a harvest night with falling leaves, pumpkins and the moon behind the white cat; source `App/Assets.xcassets/AppIcon-Spooky.appiconset/icon.svg`). It is limited to October: from November 1, or on any other theme, the usual icon comes back the next time the app is active. iOS shows its own "You have changed the icon" alert each time, so the app changes it only when it differs.
- **New chat: effort.** Once a model is chosen, an **Effort** row offers *Computer default* (the chat follows the computer's effort setting) and the levels that model takes, the same ladder as the desktop's `modelEffortLevels` (Claude 4.7 onwards, Fable and Mythos: Low, Medium, High, Extra high, Max; OpenAI reasoning models: Low, Medium, Normal, High; others: Low, Normal, High). The choice is saved with the New chat draft, carried by a chat started offline, and set with the chat's model through `session:setOptions` `effort`. A choice the next model doesn't take is cleared.
- **New chat: Run on.** When the chosen model's provider is local (`LOCAL_PROVIDER_KINDS`: llama.cpp, Ollama, LM Studio, vLLM), a **Computer → Run on** row lists the paired computers. Choosing another connects to it (one connection at a time, as before), clears the model, folder and effort since those belong to the computer, keeps the typed text, and picks that computer's last or default model. The row stays while that computer's models load.
- **Phone access (decided in this change).** `effort` joins the chat options a phone may set (`PHONE_SESSION_OPTION_KEYS`); its value must be one of `low`, `medium`, `normal`, `high`, `xhigh`, `max` (`PHONE_EFFORT_LEVELS`, written to `phone-access.json` as `effortLevels` and enforced by the Rust gate), else `value-invalid`. Effort changes only how hard the model works, so it needs no proof, unlike raising the chat mode.
- **Not yet:** Android's languages and presets (its effort and Run on are in [native-android-app.md](native-android-app.md)), a UI test of the New chat rows against a live computer, native-speaker review, and translating the extensions.

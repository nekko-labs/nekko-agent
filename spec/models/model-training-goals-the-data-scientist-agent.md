# Model training & goals (the data-scientist agent)

- **Training tab** `[shipped]`, train a model in a simple UI (purpose + dataset + base model) with full expert levers (framework, epochs, batch, lr, metric + direction, experiment/time budgets, free-form constraints). Datasets from Hugging Face, Kaggle, local paths, or URLs; base models from Hugging Face or local. A data-scientist agent runs the actual experiments in a dedicated chat session (hidden from the regular chat boards); the dashboard shows a one-line explainer of what a run does, a live stat tiles row (best score, experiments, success rate, emergent niches, self-repairs, runtime, turns), a current-champion card, and the **idea maze** (every idea tried, growing over time, path-to-leader highlighted, click a node for details). A **live "now" strip** calls out what the run is doing right this moment (an explicit "starting up…" state the instant you hit start, then the currently-running experiment plus the latest activity line), and starting a run takes you straight to its dashboard. An **Artifacts card** shows exactly what the run produced (the trained model plus each harness file), where each lives, and how to use it, with every path and the run's output folder openable in the OS file manager. Run controls are grouped as one cluster (Start · Pause · Stop) set apart from Open chat / Delete. **Harness output**: a run can produce an agent file / skill / spec beside the model for its use case. The form also takes an optional **data-scientist model** override (the model running the experiments, distinct from the model being trained; App default otherwise).
- **Goal runs (plan-first)** `[shipped; the Goals tab became Workflows 2026-08-13]`, long-running goal solving for real work, not model testing: the agent **plans first** (an ordered execution plan of concrete, verifiable steps, written before any execution), **executes** step by step (statuses + one-line outcome notes, done only when verified), and **iterates** (revises the plan when reality disagrees) until the goal is finished. Dashboard built for hours/days legibility: "working for" clock, phase chip (planning/executing/verifying/finished), the live plan checklist with progress bar, current-step card, goal-shaped stat tiles, and the activity feed. Runs auto-resume after a host restart. The dedicated Goals **tab** is gone (that nav slot is now Workflows, which covers repeatable procedures rather than one-off goals); goal runs are listed alongside training runs in the **Training** tab so any that already exist stay reachable, and `/goal` in the composer still starts a background goal task.
- **Mid-run guidance** `[shipped]`, both tabs accept hints, new approaches, or new-data pointers at any time; unconsumed hints queue as chips and fold into the agent's next turn.
- **report_experiment tool** `[shipped]`, run-driven sessions get an extra builtin tool the agent uses to register/update experiments (id, parent lineage, approach family, status incl. self-repair, score, metric, note); the host tracks the leader and replies with the current standing so the agent always knows what to beat.
- **report_artifact tool** `[shipped]`, run-driven sessions also get a tool to register the concrete outputs a run produces (kind: model / agent-file / skill / spec / dataset / code / report / other, plus a title, workspace-relative path, and how-to-use note). Upserts by path; the host logs the first sighting as a milestone. This drives the dashboard's **Artifacts card** so a finished run answers "what did I get, and where is it?" at a glance instead of leaving it buried in the log. The agent brief instructs the model to call it the moment each artifact (the trained model + every harness file) exists on disk, and to keep everything under the run's `nekko-training/<slug>` (or `nekko-goal/<slug>`) output folder.
- **update_plan tool** `[shipped]`, goal-run sessions also get a plan tool: replace=true writes/rewrites the ordered plan, upserts keep step statuses (pending/active/done/skipped) and notes current. The host logs step completions as milestones, drives the goal-run checklist live, and echoes the plan back so the agent always knows each step's id.

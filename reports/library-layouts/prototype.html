Library: type slider, collapsible groups, layout styles

Interactive prototype. Signed in as a Developer, so Web pages leads. Try the type slider, the layout slider (top right), and the group headers.

Library

  • Type slider (top left): All, then one segment per kind that has files, each with its count. The thumb slides between segments.
  • Layout slider (top right): list, small icons, large icons, full cards. Saved per profile.
  • All shows every kind as a collapsible group, expanded to start. The kind that fits the setup answer leads (Developer: Web pages; Designer: Designs; Writer and Student: Documents; Product or business: Office files).
  • Groups are a header plus large square previews with no card box around them. The canvas shows the newest items of each kind; See all moves the type slider to that kind.
  • Previews are drawn from the file's kind, name and extension. The Library still never reads file contents until you open one.
  • Motion: changing layout morphs every tile from its old place and size to its new one (340 ms, ease-out). Choosing List widens the list across the page while the canvas fades; leaving List shrinks it back. Reduced motion switches instantly.

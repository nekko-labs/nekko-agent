Behavior & handoff

  • Menu: Agent, Photo, Video, Terminal. Existing image chats retain their data and become Photo in the interface.
  • First entry is remembered per agent type and per device. Close, Escape, or Try acknowledges it; About reopens it. Merely opening a menu must not create or send anything.
  • Photo ratios: 1:1, 9:16, 3:4, 4:3, 16:9. Choose valid model dimensions; never advertise 1344×768 as exact 16:9.
  • Fold/unfold must preserve the draft, aspect ratio, model, uploads, and running job. Hinge occlusion is not content space. Native Android uses WindowManager; iOS uses available geometry and existing pane policy.
  • “iPhone Duo” is a conceptual foldable target, not an assertion of a shipping device or specific display dimensions.
  • Native Photo generation needs a reviewed authenticated channel, model discovery, job events, and recoverable offline behavior; the current phone security boundary stays intact.
  • 44pt/48dp minimum native touch targets, Dynamic Type/font scale, screen-reader order, reduced transparency, keyboard Escape/focus return, light/dark and safe areas belong in native acceptance.

No external fonts, scripts, images, trackers, credentials, or generated-media claims. Illustration is original SVG. Buttons in this design board are visual examples; real interactive behavior is tested in the Electron fixture.

Nekko Cloud: Fleet and Organizations

Settings > Nekko Cloud gets two clear items. Fleet is every computer signed in to your account, paired by signing in (#3223). Organizations are teams that share chosen computers (#2585). Builds on fleet-connect-design.html (decision 0102) and the walkthrough v3. Illustrative data.

1. The Nekko Cloud page, everything set up

Signed in, unlocked, Pro. Fleet sits right after Sync; Organizations after Fleet. The rail shows the page's items so each is one click away.

2. Before Fleet can work

Only what applies now. Each gate is one line and one action, in the Fleet section; Organizations shows the same line only when it differs.

3. This computer's switch

On by default (#3223). Turning it on also turns on Remote access with the Nekko Cloud relay, once. If you turn Remote access off yourself, it stays off and the switch says why nothing can reach you.

4. Running a chat on another computer

Two doors to the same link: Open chat on a Fleet row, and Mode > Run on in the composer. The chat then shows where it runs, always.

5. Organizations

An organization opens as its own page (breadcrumb back to Nekko Cloud), so the Cloud page stays short with several orgs. Order: share this computer, computers, members, then the org's settings.

6. Joining, and getting the org's key

Accepting gives you the roster. Seeing computers needs the org key, handed over like device approval: the new member's screen shows a code, an owner or admin types it. Designed in decision 0086, not built.

7. Removing, leaving, deleting

These can't be undone (the key moves on), so they confirm instead of offering Undo. Deleting asks for the name.

8. iPhone (Android follows its own platform, same words and order)

Phones are clients: they list and open, they don't take chats. Same Fleet and Organizations items under the Nekko Cloud profile.

5 · How it works

Where each step runs

Car micvia CarPlay
→
iPhonespeech to text, on device
→
CarCommandparse, match chat, confirm
→
Relay, end-to-end encryptedoutbox, approvals, stop
→
Your computer or a Nekko Cloud machinethe agent runs as today
  • Speech to text on the iPhone first (on-device recogniser: fast, works in tunnels). Falls back to the computer’s Whisper only when the phone can’t recognise the language on device. Never a cloud speech service.
  • Text to speech on the iPhone (system voices).
  • Nekko Cloud is not needed for voice. A Nekko Cloud machine is just another computer in the list.
  • Audio session opens only while the voice sheet is up (Apple guideline), and closes as it goes.

yes · no · cancel · the first oneAnswers a read-back or a “which one?”

Chat names match loosely (“the login chat” finds “Fix flaky login test”). Two close matches are read out as a choice. Inside a chat’s Talk, anything else is sent to that chat. “Nekko,” at the start is allowed and ignored.

Apple’s rules this design follows (CarPlay Developer Guide, Oct 2026)

  • Category: voice-based conversational (com.apple.developer.carplay-voice-based-conversation, iOS 26.4). Apple has to grant it.
  • Templates: tab bar, list, information, action sheet, alert, voice control. At most 3 deep (tab bar → chat → nothing else pushed).
  • Voice first on launch; the mic only while the voice control template shows.
  • No text or imagery in answers, and never message contents: replies are spoken only; rows show state, never what the agent wrote.
  • Never ask the driver to pick up the iPhone, and every flow works without it.
  • Works with the iPhone locked: pairing keys are readable after first unlock already; signed changes (merging a PR) are not offered in the car.
